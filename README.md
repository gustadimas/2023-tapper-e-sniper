# Tapper e Sniper

Feito em out/2023, na faculdade. Está aqui como arquivo: o código ficou do jeito que era na época.

Dois minijogos que entreguei juntos em outubro de 2023. No Sniper você precisa acertar os alvos com a mira antes do tempo acabar. O Tapper é a minha versão do jogo do barman: ele serve cerveja pros clientes em 3 fases, com menu, tela de vitória e game over.

## Como abrir

O Sniper é um projeto completo: abra a pasta `Sniper` pelo Unity Hub (Add project from disk), versão 2021.3.18f1.

Do Tapper eu só salvei os Assets. Crie um projeto 2D vazio na mesma versão e importe `Tapper/pacote-original/TapperDimas.unitypackage` (Assets > Import Package > Custom Package).

Outros projetos da faculdade: [projetos-da-faculdade](https://github.com/gustadimas/projetos-da-faculdade)
